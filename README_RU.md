# WildMarket — локальная версия

## Что входит

Полное приложение: каталог, поиск, категории, регистрация и вход, корзина,
заказы, личные кабинеты, админка, отзывы, выбор ПВЗ и расчёт доставки.
Изображения всех 24 образцов товаров находятся в папке приложения.
Стили, скрипты интерфейса, значки и шрифты включены локально.
Node.js, облачное хранилище и отдельный API-сервис не нужны.

Это независимая сборка для отдельной PostgreSQL на вашем компьютере.
Она не подключается к живому сайту и не содержит его пользователей, заказов,
паролей или резервной копии базы. Ни PostgreSQL-сервер, ни Python в архив не входят.
Фотографии новых товаров — иллюстрации; каталог заполнения содержит образцы,
а не подтверждённые реальные остатки, цены или покупки.

## Первый запуск

1. Установите Python 3.11 или новее и PostgreSQL 16 или новее.
   Запустите службу PostgreSQL. Запомните пользователя и заданный вами пароль.
2. Распакуйте архив. Откройте терминал в папке **ГОТОВО**, где находится `run.py`.
3. Установите зависимости (для этого нужен интернет):

   ```text
   python -m pip install -r requirements.txt
   ```

   Если в Windows доступна команда `py`, вместо `python` можно использовать `py`.

4. Запустите:

   ```text
   python run.py
   ```

5. При первом запуске укажите адрес `127.0.0.1`, порт PostgreSQL (обычно `5432`),
   имя отдельной базы `wildmarket_local`, пользователя и его пароль.
   Программа создаст базу, если она отсутствует и у пользователя есть право
   `CREATEDB`, затем создаст таблицы. Если такого права нет, предварительно
   создайте отдельную базу в pgAdmin и назначьте пользователя её владельцем.
6. Создайте свой аккаунт администратора: имя, email и пароль минимум 12 символов.
   Пароль при вводе не отображается.
7. По желанию согласитесь заполнить каталог 24 образцами товаров.
8. Откройте **http://127.0.0.1:8000**. Для остановки нажмите **Ctrl+C**.

Далее достаточно команды `python run.py`. PostgreSQL должна оставаться запущенной.
Данные хранятся в PostgreSQL, а не в памяти Python, и сохраняются после перезапуска.

## Команды

```text
python run.py --configure       # изменить параметры подключения
python run.py --init-db         # создать базу/недостающие таблицы без удаления данных
python run.py --create-admin    # добавить администратора, не менять существующих
python run.py --fill-catalog    # заполнить каталог образцами без повторов
python run.py --check           # проверить подключение
python run.py --port 8080       # запуск на другом HTTP-порту
```

На существующей непустой базе команда заполнения не перезаписывает товары.
Не выполняйте её в базе с рабочими бизнес-данными. Повторное заполнение уже
подготовленного каталога не создаёт дубликаты. Инициализация не обновляет
произвольные старые схемы — для этой сборки используйте отдельную базу.

## Настройки и безопасность

При настройке создаётся `settings.json`; пример структуры — `settings.example.json`.
Пароль PostgreSQL хранится в `settings.json` на вашем компьютере.
Не отправляйте этот файл другим людям. Ограничьте доступ средствами своей ОС.
В Linux/macOS файл создаётся с доступом только владельцу; в Windows проверьте ACL.
Файл `.session-key` создаётся автоматически при запуске: это случайный ключ сессий.
Не публикуйте его. После его удаления существующие входы перестанут действовать.
При повторной передаче папки исключите оба файла, загруженные пользователями файлы
и любые резервные копии базы.

Сервер слушает только `127.0.0.1`. Режим отладки выключен. Это запуск для локальной
работы, не способ публикации приложения в интернете.

## Карта, доставка и вход Google

Основной интерфейс после установки зависимостей не требует CDN.
Карта, поиск адресов и Google требуют интернет и, где требуется, ваши API-ключи.
В `settings.json` можно заполнить `yandex_maps_api_key`. Если карта не загрузилась,
доступен список ПВЗ с отдельными кнопками выбора.
Встроенный каталог ПВЗ — образец, не подключение к действующей службе доставки.
Стоимость самовывоза: 50 ₽ + 0,4 ₽ за км по прямой от центра Новомосковска.
Онлайн-эквайринг и создание отправлений у перевозчиков в эту сборку не входят.

Вход Google по умолчанию выключен. Для включения настройте свой OAuth-клиент,
разрешите callback `http://127.0.0.1:8000/auth/google/callback`, заполните
`google_client_id`, `google_client_secret` и включите `google_oauth_enabled`.
При смене HTTP-порта измените callback в настройках и в OAuth-клиенте.
Обычные регистрация и вход по email работают без этих ключей.

## Резервная копия

Используйте pgAdmin или стандартные `pg_dump` / `pg_restore` PostgreSQL.
Пример без передачи пароля в командной строке:

```text
pg_dump -h 127.0.0.1 -p 5432 -U postgres -d wildmarket_local -Fc -f wildmarket.dump
```

Храните дампы отдельно от папки приложения. Для файловых загрузок отдельно
копируйте `app/static/uploads`. Автоматического облачного резервирования нет.

## Если не запускается

- `ModuleNotFoundError`: выполните установку зависимостей той же командой Python,
  которой запускаете `run.py`.
- Ошибка подключения: проверьте службу PostgreSQL, порт, имя пользователя и пароль.
- Нет права создать базу: создайте её вручную в pgAdmin, затем `--init-db`.
- Порт 8000 занят: используйте `--port 8080`.
- Проверяйте, что вы находитесь в папке с `run.py`, а не уровнем выше.
- В архив не включена база живого сайта: новая локальная база изначально пустая.
